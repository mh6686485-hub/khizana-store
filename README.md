# خِزانة — متجر أدوات منزلية (Next.js + PostgreSQL)

## طريقة النشر على Vercel (5 دقائق)

### 1. ثبّت Vercel CLI (مرة واحدة فقط)
```
npm install -g vercel
```

### 2. من داخل مجلد المشروع، سجّل دخول وانشر
```
vercel login
vercel --prod
```
هيسألك أسئلة بسيطة (اسم المشروع، إلخ) — اضغط Enter على الافتراضي في أغلبها.

### 3. اربط قاعدة بيانات Postgres مجانية
- روح لمشروعك على vercel.com → تبويب **Storage**
- اضغط **Create Database** → اختار **Postgres** (Neon) → **Free**
- Vercel هيربط متغير البيئة `DATABASE_URL` أو `POSTGRES_URL` تلقائيًا بالمشروع

### 4. أعد النشر عشان يقرأ متغير قاعدة البيانات
```
vercel --prod
```

### هتلاقي:
- المتجر شغال على الرابط اللي هيديهولك Vercel
- لوحة التحكم على `/admin` — كلمة المرور الافتراضية: `khizana2026` (غيّرها فورًا من تبويب "الإعدادات" داخل اللوحة)

## ملاحظات مهمة
- أول مرة تفتح فيها أي API route، السيستم بينشئ الجداول ويحط بيانات تجريبية تلقائيًا — مفيش خطوة إعداد يدوية لقاعدة البيانات.
- لربط دومين خاص بيك: من إعدادات المشروع على Vercel → **Domains** → أضف الدومين واتبع تعليمات الـ DNS.
- كلمة مرور الأدمن محفوظة كنص عادي في قاعدة البيانات — مناسبة للبداية، لكن لو هتشتغل على نطاق واسع يفضل الترقية لنظام تسجيل دخول حقيقي (مثل NextAuth).
